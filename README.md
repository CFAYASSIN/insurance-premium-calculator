# Insurance Premium Calculator

## Project Overview
This is my first Python project. It calculates total insurance premiums collected and profit after claims paid.

## Objectives
- Calculate total premiums collected.
- Calculate profit after paying claims.
- Practise basic Python programming.

## Technology Used
- Python 3

## Example Data
- Number of customers: 50
- Premium per customer: TZS 20,000
- Total claims paid: TZS 600,000

## Results
- Total Premium Collected: TZS 1,000,000
- Profit After Claims: TZS 400,000

- Variables
- Multiplication and subtraction
- `print()` statements
